# Premium Fruits (local)

Clean local mirror of premiumfruitbd.com.

## Structure

```
index.html
server.js
package.json
assets/
  css/styles.css
  js/          # app modules (polyfills, vendor, main + chunks)
  media/       # images, fonts, icons
  favicon.ico
data/          # cached API JSON
```

## Run

```bash
npm start
```

Open http://localhost:4173
